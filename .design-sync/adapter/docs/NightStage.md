The void page stage. Night Trail is dark-first — wrap any composition that is not already on a dark page (embeds, white artboards) so surfaces, glow, and the text ramp read as designed. Page-level designs get this for free from the body styles.

```jsx
<NightStage>
  <SectionHeader eyebrow="// Field Notes" iconName="articles" title="Articles" />
  <ProductGrid>…</ProductGrid>
</NightStage>
```
