HUD targeting reticle: cyan L-brackets top-left + bottom-right of an image with an optional mono corner label. Makes field photos read like recon footage.

```jsx
<HudFrame label="// REC">
  <img src="/photos/trail-run.jpg" alt="Cybertruck on the trail" width={600} height={400} />
</HudFrame>
```
