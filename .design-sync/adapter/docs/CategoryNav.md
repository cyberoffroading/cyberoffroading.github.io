Sticky translucent site header: neon wordmark left, horizontally-scrolling NavPill row right. Mark exactly one pill active.

```jsx
<CategoryNav>
  <NavPill href="#articles">Articles</NavPill>
  <NavPill href="#offroad" active>Offroad</NavPill>
  <NavPill href="#recovery" tone="red">Recovery</NavPill>
</CategoryNav>
```
